Talk rate at the institutions with the most abstracts.

Credit goes to every institution of the first author, or, with the toggle, of the senior (last) author. An abstract can count for several institutions, so rows don't sum to the total. Institutions are resolved with a hand-curated list of 211 institutions, which places about 70% of abstracts. The figure shows the 20 highest talk rates among the 50 institutions with the most abstracts each year; the tables list all 50, except any without a talk that year.
